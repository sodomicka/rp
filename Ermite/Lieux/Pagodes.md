# Pagodes

- version : W1

## Pagode des ames errantes
- Nature : residence de Jizo. Pagode en foret, au-dela du Rukongai.
- Anciennete : lieu de vie fraternel avant le depart d'Ichibe pour le Palais (des siecles de the partages).
- Fonction narrative : ermitage, point d'ancrage hors institutions, lieu promis (jamais offert) a Yachiru.
- Etat an 0 : intacte, occupee par Jizo.

## Pagode du Seireitei
- Nature : pagode de la 4e division, construite a l'initiative de Jizo entre -200 et 0.
- Rattachement : 4e division (Unohana).
- Fonction narrative : ancrage de Jizo dans le Seireitei sans grade ni appartenance ; planque preferee de Shunsui Kyoraku.
- Etat an 0 : intacte.
