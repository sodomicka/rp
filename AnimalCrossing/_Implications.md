Socle COMPLET pour les personnages que Remus croise souvent (Marie, Blanche, habitants de Pont-la-Plaine, Nook et ses proches) ; socle LEGER (physique, psychologie, role, malediction) pour les personnages lointains (parents, fratrie de Lupus, absents). Un item non fourni se demande dans le meme message que les autres questions, jamais apres ; un item juge inutile par le worldbuilder ne se redemande pas.
- Rythme : chaque livraison enchaine dans le meme message avec le canon et les questions de la fiche suivante. Un tour sans questions est un tour perdu.
- Villageois nommes : CANON par defaut (pool AC de 400+ villageois) ; le worldbuilder precise quand c'est un OC. Ex. : Olivia, ex de Remus = l'Olivia canon (chatte, caractere Arrogante).
