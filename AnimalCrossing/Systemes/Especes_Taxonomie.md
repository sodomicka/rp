# Especes_Taxonomie

- version : W3

## Principe
- Personne = espece douee de raison, dite "sapiens". Critere : la RAISON (logique de niveau humain). Sinon : animal.
- Especes sapiens et animaux sans raison : deux evolutions DISTINCTES. Ex. pieuvres sapiens / pieuvres pechables.
- Tout sapiens descend a l'origine d'un croisement bete x humain : voie sexuee chez les mammiferes, fecondation in vitro pour les autres. Ex. Lepus sapiens <- Lepus americanus x Homo sapiens.
- Les sapiens sont communs. Les raretes : les humains, et les hybrides recents ou actuels (Tanuki, Kappa, hybrides ~1/10 000).
- Humains : espece rare, au meme rang que les autres sapiens ; aussi peu nombreux que les especes d'entre-soi a 1 ou 2 petits.
- Mecanismes d'origine, portees, hybrides : cf. Systemes/Reproduction_Hybridation.md.
- Rang de chaque espece dans la chaine alimentaire et sociale : cf. Systemes/Hierarchie_Predation.md.

## Vocabulaire
- sapiens : toute espece douee de raison, humains compris. Terme de la norme actuelle.
- Anthro : sapiens non humain. Terme maintenu par lobbying humain : se distinguer en rappelant que les humains precedaient, au risque de rappeler l'acte a l'origine des Anthros.
- hybride : aujourd'hui, uniquement le cas hors norme a ~1/10 000. A l'origine, designait les premiers Anthros ; devenus la norme, ils ont perdu l'etiquette.
- Comptage des parts : un Anthro etant mi-bete mi-humain par origine, les parts d'ascendance se comptent. Ex. un Lepus sapiens x Homo sapiens = 1/4 lievre, 3/4 humain. Le dire est TABOU : ca rappelle que tout Anthro est un hybride d'origine.

## Plan de corps
- Tout Anthro a la forme globale et les organes reproducteurs d'Homo.
- Bipede, torse droit, tete au-dessus du torse a 90 degres de l'axe de la colonne, regard a l'horizon.
- Consequence : les pieuvres sapiens sont des vertebres.

## Nomenclature
- Convention : "Genre sapiens", epithete en minuscule (ex. Homo sapiens).
- Plusieurs sapiens dans un meme genre : troisieme terme = epithete reelle (ex. Panthera sapiens leo, Panthera sapiens tigris).
- Loups : Lupus sapiens. Lobbying massif des apex pour retirer "Canis" : effacer par decret la parente avec les chiens. Sans ce retrait, ils seraient Canis sapiens lupus, meme espece que les chiens [IMPLICITE].
- Chiens : Canis sapiens, toutes races confondues.
- Hybrides : notes Genre x Genre (ex. Lupus x Homo, Lepus x Homo). Peu documentes : personne ne sait vraiment ce qu'ils sont.
- Fusions (meme espece reelle) : oursons -> ours ; lapins + lievres -> Lepus ; vaches + taureaux -> Bos ; cochons + sangliers -> Sus.
- Genre fixe par personnage (plusieurs genres reels) : oiseaux (hors hirondelles), aigles, singes, elephants.
- Ex. : Niko, langur gris -> Semnopithecus sapiens.
- "Lupus Lupus" : nom de la ville de Lupus, pas d'une espece.

## Especes mystiques
- Lignees hybrides de branches lointaines, stabilisees en espece au fil des generations : les creatures de legende.
- Tanuki sapiens : hybride Procyon x Nyctereutes, normalise depuis plusieurs generations. Rare. Famille Nook.
- Kappa sapiens : hybride Chrysemys x Dendrobates, normalise depuis plusieurs generations. Rare.
- Les especes ancetres existent toujours en sapiens.

## Exclusions
- Aucun sapiens : poissons (requins compris), insectes, plantes, champignons, etc. In vitro tente, echec : ce sont les limites du modele.
- "Poisson" est un grade paraphyletique, pas un clade : l'exclusion tient a l'echec, pas a la distance evolutive.
- Aucun spectre ni etre de neige. La "race mysterieuse" de Jacqu'O est une histoire d'epouvante inventee : c'est un humain deguise.
- Gyroides : etres artificiels (mineral anime par une mousse mutee, Bryum sensitivum), hors taxonomie. Raisonnent mais ne sont pas des personnes. Detail : cf. Systemes/Gyroides.md.

## Parentes et animaux sans raison
- Loups et chiens : origine commune ; les races de chien plus encore.
- Animaux de compagnie mammiferes sans raison : existent. Ils choquent surtout "ceux d'en bas" : proies et classes populaires, qui se confondent.
