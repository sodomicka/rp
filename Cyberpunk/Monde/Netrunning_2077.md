# Netrunning 2077

- version : W2

## 1. Equipement de base
- Interface neurale (port d'interface) obligatoire : le netrunner se branche par cable ou a courte portee sans fil.
- Cyberdeck : implant de systeme d'exploitation, porte les quickhacks et la RAM. Marques 2077 : Arasaka, Militech (gamme Canto), Raven Microcyber, Tetratronic Rippler, NetWatch Netdriver, Biotech Sigma [INCERTAIN sur l'exhaustivite].
- Un corps ne porte qu'un OS : cyberdeck OU Sandevistan OU Berserk.
- RAM : ressource de calcul consommee par chaque quickhack, se regenere avec le temps.
- Combinaison de netrunner : refroidissement et isolation, indispensable en plongee longue. Bain de glace pour les immersions profondes (Voodoo Boys, Songbird).
- Implants de cortex frontal (memoire, ex-disk) : augmentent RAM et vitesse de traitement.

## 2. Quickhacks
- Programmes injectes dans une cible connectee (humain chrome, drone, camera, tourelle, vehicule) a travers le reseau local.
- Familles : furtifs (Ping, Reboot Optics, Sonic Shock, Memory Wipe) ; controle (Cyberware Malfunction, Weapon Glitch) ; combat (Short Circuit, Overheat, Contagion, Synapse Burnout) ; ultimes (System Reset / Collapse, Cyberpsychosis, Suicide, Detonate Grenade).
- Blackwall Gateway : quickhack unique, ne tourne que sur le deck Militech Canto MK6. Ouvre une breche vers l'au-dela et laisse une IA rogue detruire la cible. Origine : programme NUSA / Songbird, bunker Cynosure. cf. Net_et_Blackwall.md S3.
- Breach Protocol : intrusion dans un reseau, injection de daemons (Icepick, Datamine, Mass Vulnerability, etc.) qui affaiblissent tout le sous-reseau.

## 3. Le Net de 2077
- Pas de reseau mondial ouvert : reseaux locaux (CitiNet, subnets d'immeuble, intranets corpo), points d'acces physiques, Data Terms.
- Acces au vieux Net : noeuds scelles par NetWatch. Rouvrir un noeud = crime capital de facto (NetWatch flatline sans proces).
- Intranets corpo (Arasaka, Militech) : ICE noir, tracage, contre-intrusion humaine.

## 4. ICE, tracage, flatline
- ICE (Intrusion Countermeasures Electronics) : defenses actives. ICE noir = letal, feedback neural, "netrunner frit" (flatline).
- Tracage : un netrunner repere peut etre localise physiquement puis frit a distance. Cas canon : T-Bug, tracee par Arasaka pendant le braquage du Konpeki Plaza, morte en direct. cf. Personnages/T_Bug.md.
- Deconnexion forcee en pleine plongee : coma, lesions cerebrales, mort. cf. deploiement du mur, Net_et_Blackwall.md S3.

## 5. Plongees profondes et vieux Net
- Programme Arasaka (annees 2060-2070) : enfants netrunners envoyes fouiller l'Old Net pour recuperer des donnees ; la plupart meurent ou deviennent fous (Edgerunners, passe de Lucy).
- Rituels Voodoo Boys : bains de glace, immersion collective, tentatives de contact avec Alt et les IA. Brigitte n'y va pas elle-meme ; elle envoie un intermediaire (V, en canon).
- "Percer le mur" : atteindre un point de contact avec l'au-dela sans que le mur (l'IA-ICE) identifie l'intrus. Aucun protocole public.
- Ceux qui l'ont fait : Alt (de l'interieur) ; Songbird (par breche NUSA) ; Silas Null (seul, 2075, [DIVERGENCE RP]).
