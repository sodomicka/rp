# Auto Memory Dolls

- version : W1
- sources : episodes (via Wikipedia EN), site officiel de l'anime (rubrique Monde, via fandom), fandom. Roman exclu.
- graphies : Auto Memory Doll (var. Auto Memories Doll, Auto Memoir Doll). Graphie definitive au lexique de la BIBLE.

## 1. Definition
- Auto Memory Doll, dite "Doll" : ecrivaine publique. Elle redige les lettres de ceux qui ne savent pas ecrire, ou qui ne savent pas mettre des mots sur ce qu'ils ressentent.
- Outil : la machine a ecrire. Metier presque entierement feminin.
- Une Doll traduit en mots les sentiments du client : c'est ce qui distingue une vraie Doll d'une simple dactylo (ep. 2-3).

## 2. Origine
- Le nom : [INCERTAIN] a l'origine, une machine a transcrire la voix, inventee par le docteur Orland pour sa femme Molly, romanciere devenue aveugle. Attestee par le fandom, presence dans l'anime non verifiee.
- Molly Orland, romanciere aveugle : c'est la lecture de son roman qui a donne a Erica l'envie de devenir Doll (anime).
- Le metier (site officiel) : pendant la guerre, la mobilisation totale vide les bureaux. Les femmes prennent le travail d'ecritures, d'abord comme volontaires, dans l'armee puis partout.
- L'armee cree des ecoles de dactylographie dans ses installations. Formation de six semaines, reduite a quatre puis a deux sous la pression des besoins.
- Apres-guerre : demobilisation, mais reconstruction et paperasse de demobilisation enormes. Les ecoles militaires sont cedees au prive, fusionnees avec la sous-traitance du service postal national : elles deviennent les ecoles de Dolls.
- Doll devient l'un des metiers qui font rever les femmes emancipees par la guerre (site officiel).

## 3. Le metier
- Qualites attendues : frappe precise, grammaire et orthographe sures, rapidite, et capacite a saisir les vrais sentiments du client pour les porter dans la lettre.
- Formation : ecole de Dolls (ep. 3). Instructrice : Rhodanthe. Le diplome exige une lettre qui transmet vraiment un sentiment ; Violet echoue d'abord, puis l'obtient.
- Employeurs : les compagnies postales. CH Postal (Leiden, dirigee par Hodgins) est a la fois service de courrier prive et service d'ecriture (ep. 1).
- Acces : le client passe a la compagnie, ou fait venir une Doll chez lui.
- Missions : partout sur le continent, parfois pour de longs sejours. Exemples canon : correspondance amoureuse publique entre deux familles royales (ep. 5), copie de livres rares dans un observatoire (ep. 6), ecriture d'une piece de theatre (ep. 7), lettres a remettre apres la mort de la cliente (ep. 10), lettres d'adieu d'un soldat sur un front de guerre civile (ep. 11).
- Dolls connues a CH Postal : Violet, Cattleya (la plus demandee), Erica, Iris. Luculia : diplomee de la meme promotion que Violet (ep. 3).

## 4. Regles d'emploi [INCERTAIN]
Donnees par le fandom sans source identifiable (anime ou roman) :
- pas de client anonyme ni sous pseudonyme ;
- 30 jours de service maximum par client ;
- la Doll ne fait que ce que le client demande ; le reste n'engage pas sa compagnie ;
- une Doll envoyee en zone de conflit peut porter une arme a feu.
