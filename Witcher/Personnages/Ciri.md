# Ciri

- version : W1

Fiche neutre (Personnages/). Personnage canon (livres de Sapkowski, The Witcher 3). Etat a mai 1272. Divergences RP balisees.

## Identite

- Cirilla Fiona Elen Riannon. Ciri ; Zireael, l'Hirondelle (Vieux Langage) ; la Lionne de Cintra ; Falka (nom pris chez les Rats) ; l'Enfant du Sang Ancien.
- Nee 1252 ou 1253 [INCERTAIN], Cintra. Fille de Pavetta (fille de Calanthe) et de Duny, alias Emhyr var Emreis. 19 ou 20 ans en 1272.
- Porteuse du Sang Ancien, lignee de Lara Dorren (cf. Lore/Sang_Ancien) ; Source.
- Enfant-surprise de Geralt (Loi de la Surprise, Cintra).

## Description physique

- Cheveux gris cendre, longs ; yeux verts ; cicatrice sur la joue gauche. Silhouette de bretteuse.
- Tenue de 1272 : chemise blanche, corselet, pantalon, bottes ; epee elfique Zireael dans le dos.

## Capacites

- Sang Ancien : teleportation, passage entre les mondes et dans le temps ; controle imparfait, declenche par le stress ou la volonte. Entrainee par Avallac'h depuis 1268.
- Escrime a la sorceleuse (Kaer Morhen, Rats, Bonhart) ; aucune mutation, aucun signe.
- Source : puissance brute, mal maitrisee. Nilfgaard, la Loge, les Aen Elle et la Chasse Sauvage la veulent pour cela.
- Prophetie d'Ithlinne : cle du Froid Blanc (cf. Lore/Froid_Blanc).

## Psychologie

- Volontaire, impulsive, indomptable ; fuit toute instrumentalisation (Nilfgaard, Loge, Aen Elle, Vilgefortz).
- Loyale a Geralt et Yennefer, ses parents de coeur ; coupable envers ceux qu'elle entraine dans ses fuites.
- Traumatismes : Cintra, les Rats, Bonhart, Stygga, Tir na Lia. Confiance difficile.
- Finit toujours par affronter ce qu'on lui assigne.

## Histoire jusqu'au point de depart (mai 1272)

- 1252-1253 : naissance a Cintra ; pupille de Calanthe.
- 1264 : chute de Cintra, Cahir ; fuite ; recueillie par Geralt ; formee a Kaer Morhen, soignee par Triss ; Ellander, temple de Melitele, formee a la magie par Yennefer.
- 1267 : Thanedd ; Tor Lara ; desert de Korath ; les Rats, "Falka" ; Bonhart, Skellen, Rience.
- 1267-1268 : Tor Zireael ; monde des Aen Elle (Tir na Lia, Auberon, Eredin, Avallac'h) ; evasion ; Stygga : Vilgefortz tue, Geralt et Yennefer retrouves.
- 1268 : Rivie ; emporte Geralt et Yennefer hors du monde ; part avec Avallac'h. Ouverture entre spheres reconnue par de Meure [DIVERGENCE RP].
- 1268-1272 : erre avec Avallac'h entre les mondes, la Chasse Sauvage (Eredin) a ses trousses ; apprend son don.
- Printemps 1272 : retour dans ce monde. Ouverture sentie par Wanda, reconnue par de Meure [DIVERGENCE RP]. Passages a Skellige (Hindarsfjall), Velen, Novigrad ; ordre, dates et rencontres : roadmaps R2-R7 (build) [INCERTAIN].
- Mai 1272 : Emhyr sait son retour et charge Geralt de la retrouver. Elle ignore tout de Wanda.

## Relations

- Geralt : pere par destin. Yennefer : mere de coeur. Emhyr : pere de sang, refuse. Calanthe : grand-mere, morte en 1264.
- Vesemir, Eskel, Lambert : famille de Kaer Morhen. Triss : l'a soignee enfant. Jaskier : ami.
- Avallac'h : mentor et gardien, promis a Lara Dorren, la veut pour le Sang Ancien. Eredin, la Chasse Sauvage : chasseurs.
- Wanda [DIVERGENCE RP] : la localise en continu (cf. Systemes/Power_scaling) ; troisieme nom du filet promis a Geralt ; role a venir non ecrit (R8). Ciri ignore son existence.
