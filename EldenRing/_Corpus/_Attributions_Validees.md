## Statut des attributions

Une attribution est ETABLIE quand le locuteur se nomme dans la meme section, ou quand le
corpus le nomme ailleurs de maniere non ambigue. Elle est VALIDEE PAR LE WORLDBUILDER quand
elle repose sur la connaissance du jeu que le texte seul ne porte pas : dans ce cas, elle est
tracable ici et revocable.

## ALERTE - le corpus contient du contenu coupe

Redeemer Guilbert, alias Mercenary Swordsman, a ete coupe de la version finale d'ELDEN RING.
Ses dialogues figurent pourtant dans le dump, sans aucune marque les distinguant du contenu
actif.

Consequence GENERALE, qui depasse ce cas : la presomption implicite du build - tout ce qui est
dans le corpus est dans le jeu - est FAUSSE. Le dump est un dump de FICHIERS, pas de contenu
joue. Il peut contenir des PNJ coupes, des repliques non utilisees, des variantes abandonnees.

Le MJ ne peut PAS detecter ces cas : rien dans le texte ne les signale, et la doctrine interdit
de fetcher une source externe de sa propre initiative. Seul le worldbuilder peut les identifier.

Regle retenue (decision du worldbuilder, 2026-07-25) : LE CONTENU COUPE EST CONSERVE ET
EXPLOITABLE. Il porte la balise [COUPE], qui dit son statut sans le disqualifier.

- Ce qu'il n'est pas : un fait ETABLI du monde joue. Il n'est jamais entre dans le jeu final.
- Ce qu'il est : une source officielle de FromSoftware, ecrite pour cet univers, donc du
  materiau de lore legitime - superieur a une theorie de fans, inferieur au contenu joue.
- Ce qu'on en fait : le worldbuilder peut s'en servir librement pour combler un trou. Le fait
  comble garde la balise [COUPE] qui trace sa provenance, donc reste revocable.

Le cas est frequent dans les zones ou le lore joue est mince : une intention abandonnee y dit
souvent ce que les auteurs avaient en tete, et c'est precisement ce dont un RP a besoin.

Cas connus a ce jour : Guilbert (bloc 3030), cite par Systemes/Crucible.md a propos d'Ordovis.
