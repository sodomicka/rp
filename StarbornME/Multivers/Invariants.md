# Invariants et variables du multivers

- version : W1

## Racine de divergence

- MACRO stable, MICRO variable. Biographies individuelles comprises.
- Un univers = une variante de Mass Effect. Jamais un autre monde.
- Tout ce qui n'est pas liste comme invariant est presume variable.

## Socle Starborn (invariant)

- Mecanique Starfield intacte : artefacts, visions, armillaire, Unite, NG+.
- Passage de l'Unite = aller simple.
- Memoire conservee a travers toutes les iterations.

## Moissonneurs

- Arrivee du cycle : INVARIANTE.
- Denouement : VARIABLE (certaines iterations sont moissonnees).
- Catalyseur : INVARIANT.
- Creuset : INVARIANT des univers qui gagnent.

## Shepard

- Existence : INVARIANTE.
- Biographie : VARIABLE (genre, origine, psychologie, choix - tout).
- Mort : INVARIANTE. Il ne survit jamais : soit il meurt dans la guerre, soit il se sacrifie pour vaincre.
- Reciproque : les Moissonneurs ne sont JAMAIS vaincus autrement que par le sacrifice de Shepard. Victoire <=> sacrifice de Shepard. [DIVERGENCE RP] : ecarte la fin canon ou Shepard survit.
- Consequence : Aria sait, des 2183, comment finit tout Shepard qui gagne. Cette Tali ne le sait pas.

## Aria

- Existence : INVARIANTE.
- Regne sur l'Afterlife : VARIABLE. Aria reine d'Omega est du decor d'univers, pas un invariant.
- Maternite : VARIABLE. Liselle existe dans certains univers, pas dans d'autres.
- L'invariante d'Aria est la Starborn ; la cheffe de la pegre du canon est une variante parmi d'autres.

## Tali

- Existence : INVARIANTE. Nature exacte de l'invariance : A TRANCHER (cf. _Implications.md).
- Biographie : VARIABLE (racine de divergence).

## Le couple

- Amour de chaque Starborn pour l'autre : INVARIANT, dans chaque univers, envers chaque version de l'autre, que la version locale le rende ou non.

## Geographie

- Citadelle : INVARIANTE.
- Relais cosmodesiques : INVARIANTS.
- Omega, le rocher : INVARIANT.
- Omega, la station : VARIABLE.

## Univers joue (rappel de position)
