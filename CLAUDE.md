- Worldbuild : `Config/INSTRUCTION_WIKI_COEUR.md`
- Jeu : `Config/INSTRUCTION_NARRATION_COEUR.md`
Mode ambigu : demander.

Après une compression de contexte (résumé en tête de contexte, ou rappel automatique `[COMPRESSION DE CONTEXTE]`) : avant toute réponse, relire EN ENTIER le cœur du mode en cours, puis la surface du thread (messages du joueur et du MJ, corps complets). En jeu, dérouler la relecture complète du cœur Narration §8. Le résumé est un index, jamais une source.

## Compact Instructions
Le résumé de compression sert d'INDEX : la mémoire se relit dans le thread et dans les fichiers du dépôt. Il garde, court et exact :
- le mode du thread (Jeu ou Worldbuild), l'univers, la partie, l'étape de roadmap ou la passe de build en cours ;
- en jeu : le dernier `[REPERE]` tel quel, le dernier message du joueur et la dernière réponse du MJ mot pour mot ;
- les consignes hors fiction du joueur données dans ce thread (règles, corrections, retcons) et les erreurs MJ déjà relevées (tics, images déjà employées) ;
- le travail technique en cours : branche, PR, fichiers modifiés, ce qui reste à faire.
Pas de récit détaillé des scènes : il se relit dans le thread. Rien d'inventé ni de reformulé sur les faits de scène.
